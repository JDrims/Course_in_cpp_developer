# Задание 1. Написать первую программу

1. Создайте проект в IDE.

2. В созданном проекте откройте файл main.cpp (если он не был создан автоматически, создайте его вручную). Появится стандартный код ниже:

```cs
#include <iostream>

int main() {
  std::cout << "Hello World!\n";
}
```

3. Измените текст в кавычках "Hello world!" на своё имя, например "Евгений". Не удаляйте символы \n в конце этой строки.

```cs
#include <iostream>

int main() {
  std::cout << "Евгений\n";
}
```

4. Запустите программу, нажав кнопку `Запуск`. На экране вы получите результат выполнения программы – вывод текста «Евгений».

```
Евгений
```

5. Добавьте ещё одну строку с выводом вашего возраста, например 28. Обратите внимание на отсутствие кавычек вокруг числа и отдельный символ переноса строки.

```cs
#include <iostream>

int main() {
  std::cout << "Евгений\n";
  std::cout << 28 << "\n";
}
```

6. Запустите программу. На экране вы увидете текст:

```
Евгений
28
```

1. Задача выполнена.
