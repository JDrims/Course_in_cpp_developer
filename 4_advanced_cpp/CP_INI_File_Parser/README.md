## Описание проекта

Консольное приложение-библиотека для чтения и разбора INI-файлов. Проект реализован на **C++** с использованием **объектно-ориентированного подхода**, **шаблонов**, **исключений** и **CMake** для сборки.

Парсер читает INI-файл, хранит содержимое в памяти в виде «секция → ключ → значение» и предоставляет пользователю шаблонную функцию `get_value<T>` для получения значения по пути вида `"section.key"` с автоматическим преобразованием в нужный тип.

### Основные возможности

- Чтение INI-файла построчно с корректной обработкой:
  - секций `[Section]`,
  - переменных `key = value`,
  - комментариев `; comment` (полных и inline),
  - пустых строк,
  - пробелов и табов вокруг имён, значений и скобок.
- Хранение значений в виде строк в структуре `std::map<std::string, std::map<std::string, std::string>>`.
- Поддержка повторяющихся секций — переменные дополняются, значения перезаписываются.
- Шаблонная функция `get_value<T>` с поддержкой типов:
  - `int`,
  - `double`,
  - `std::string`.
- Иерархия исключений для разных ситуаций:
  - файл не открылся,
  - ошибка синтаксиса в файле,
  - секция не найдена,
  - ключ не найден,
  - значение не преобразуется в запрошенный тип.
- Разделение ответственности по слоям: чтение файла, разбор строки, хранение, доступ к данным.
- Покрытие ключевых сценариев модульными тестами без внешних зависимостей.

---

### Реализованы дополнительные возможности

**1. Номер строки при синтаксической ошибке.**  
Исключение `ini_syntax_error` хранит номер строки, на которой встретилась проблема, и возвращает его через метод `line()`. Это позволяет пользователю быстро найти ошибку в файле.

**2. Подсказка при отсутствии ключа.**  
Если пользователь запросил переменную, которой нет в секции, исключение `ini_key_not_found` формирует подсказку — список всех переменных, которые в этой секции есть. Если секция пустая, сообщение об этом говорит явно.
