# Домашнее задание к занятию "Тестирование и Unit-тесты"

## Описание задания
Необходимо доработать класс **ExtArray** согласно заданиям.

## Инструкция к выполнению
Исходный код класса находится в дополнительных материалах к домашнему заданию.

## Задание 1
Доработайте тестовые кейсы для класса **ExtArray** таким образом, чтобы они проверяли работу методов класса с пустыми массивами.
    - Если массив пустой, то корректной работой метода будет считаться возврат значения **0**.

## Задание 2
1. Перегрузите метод `mean()` таким образом, чтобы он вычислял среднее арифметическое для указанного диапазона массива.
   - Новый метод должен принимать начальный и конечный номер диапазона и возвращать среднее арифметическое значение только для данного диапазона.
   - Если значения для номеров указаны неверно (начальный номер больше или равен конечному), то метод должен возвращать исключение `std::invalid_argument`.
2. Создайте unit-тест для этого метода. Тест должен проверять результаты работы метода как с правильными номерами диапазона, так и с ошибочными.

## Задание 3.
1. Дополните класс **ExtArray** методом `checkSum`, возвращающим контрольную сумму для битового массива (содержащего только нули и единицы).
   - Метод должен работать только с массивами типа `bool` и `int`. Если тип элементов массива отличается от данных двух, то выбрасывается исключение `std::bad_typeid`.
   - Метод должен проверять содержание целочисленного массива. Если в массиве присутствуют значения, отличные от **0** и **1**, то выбрасывается исключение `std::logic_error`.
   - Для целочисленных и булевских массивов метод возвращает количество элементов, установленных в значение **1**(`true`).
2. Напишите тестовые кейсы на проверку типа массива, проверку содержимого массива и на проверку правильности результата.
Инструменты, которые пригодятся для выполнения задания
Среда разработки **Visual Studio** или система сборки **CMake**.
